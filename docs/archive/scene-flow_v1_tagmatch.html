1. 한눈에 보기

한 줄 요약 — 만보와 솜이 태그로 싸우며 토너먼트 3경기를 이기고, 이긴 상대를 동료로 맞아 챔피언이 되는 2D 실시간 배틀 게임
  • 장면은 모두 7개이고, 경기·영입·대진표가 3번 반복됩니다.
  • 지면 같은 경기를 바로 다시 합니다. 대진표로 돌아가지 않아 시연 흐름이 끊기지 않습니다.
  • 결승에서 이기면 영입 장면 없이 엔딩으로 갑니다.

2. 장면별 상세

① 로고LogoScene

1.5초
화면 구성검은 배경 가운데 팀 로고 "보솜보솜"이 나타났다 사라짐. 로고 이미지가 없으면 글자로 표시
입력클릭하거나 아무 키나 누르면 바로 넘어감. 이 첫 클릭부터 소리가 나옴(브라우저 정책)
다음 장면 조건연출이 끝나거나 클릭했을 때, 게임 리소스 준비가 끝났으면 → ② 오프닝 배틀
뒤에서 하는 일그림, 소리, 데이터를 미리 불러와서 이후 장면이 끊김 없이 이어지게 함

② 오프닝 배틀OpeningBattleScene

25초 (최대 30초)
화면 구성실제 배틀과 같은 전투 화면. 상대는 이름 없는 강한 라이벌 1명
진행
  1. 만보 혼자 싸우며 체력이 빠르게 줄어듦
  2. 체력 30% 이하 또는 12초 경과 → 느린 화면과 함께 솜 난입
  3. 태그 키 그림만 크게 깜빡임(설명 문장 없음)
  4. 태그 → 합동기 → 상대가 장외로 날아감
입력이동, 공격, 스킬, 태그 (키 배치는 뒤쪽 "공통 사항" 참고)
다음 장면 조건장외 연출이 끝나면 → ③ 타이틀
안전 장치만보는 쓰러지지 않음. 5초 동안 태그를 안 누르면 자동으로 태그 → 이 장면에서는 실패가 없음

③ 타이틀TitleScene

5초
화면 구성게임 제목, 메뉴 "시작하기"·"설정", 배경에 만보와 솜. 웹게임이라 게임 종료 메뉴는 없음
설정같은 화면 위에 작은 창으로 열림. 사운드 크기 조절과 닫기만 있음
입력마우스 클릭, 또는 방향키로 고르고 Enter
다음 장면 조건"시작하기" → ④ 대진표

④ 대진표BracketScene

첫 방문 8초 · 이후 4초
화면 구성10개 팀 토너먼트 대진표. 우리 팀은 강조 색, 다음 경기 칸은 빛나는 버튼
첫 방문상대 팀 추첨 룰렛(약 3초). 연출은 룰렛이지만 결과는 미리 정한 순서로 고정해 매번 같은 흐름이 나옴
다시 방문추첨 없이 우리 팀 승리선이 다음 칸으로 이어지는 연출(1초)
입력다음 경기 칸 클릭 또는 Enter
다음 장면 조건다음 경기 칸 클릭 → ⑤ 배틀

⑤ 배틀BattleScene

8강·4강 25초 · 결승 30초
화면 구성
  • 위: 양 팀 체력바와 현재 캐릭터 얼굴
  • 아래: 스킬 2개 재사용 대기 표시, 태그 게이지, 영입 동료 아이콘
  • 가운데: 양 끝이 화면 밖으로 열린 무대
입력이동, 공격, 스킬 2개, 태그. 태그 게이지가 찼을 때만 교체와 합동기 가능
승리상대 체력 0 → 잠깐 멈춤 → 장외로 날아가 별이 됨 → 2초 뒤 종료
8강·4강은 → ⑥ 영입, 결승은 → ⑦ 엔딩
패배"다시 한 번!" 1초 표시 후 같은 경기를 바로 다시 시작

⑥ 영입RecruitScene

6초
화면 구성쓰러졌던 상대 멤버가 일어나 다가옴 → 말풍선 "○○이(가) 동료가 되고 싶어 한다!" → 아래 파티 4칸 중 빈칸에 들어감
입력클릭 또는 Enter로 건너뛰기. 누르지 않아도 자동으로 넘어감
다음 장면 조건연출이 끝나면 → ④ 대진표(다음 경기)
건너뛰는 경우결승 승리 후에는 이 장면 없이 엔딩으로 감

⑦ 엔딩EndingScene

18초
화면 구성
  1. 챔피언 등극(5초): 트로피, 파티 전원 등장, 꽃가루
  2. 개발 로그 크레딧(9초): "기획부터 구현까지 4일" → Day 1~4가 한 줄씩 올라감
  3. 마지막 화면(4초~): "챔피언 팀의 다음 동료는?" + 빛나는 빈 슬롯 1칸
입력1·2단계는 클릭하면 다음 단계로 넘어감
다음 장면 조건없음. 마지막 화면에 멈춰 발표 멘트로 이어감(R 키를 누르면 처음으로)

공통 사항

조작 키 (제안) — 이동 ←→ 또는 AD, 점프 ↑ 또는 W, 공격 J, 스킬 KL, 태그 Space
숫자 키는 시연용 단축키로 쓰기 때문에 조작에 넣지 않았습니다.
캐릭터 그림이 아직 없을 때 — 도형으로 대신 보여 주고 게임은 끝까지 진행됩니다. 그림 파일을 정해진 폴더에 넣기만 하면 다음 실행부터 자동으로 그림이 나옵니다.
요소도형으로 표현하는 방법
몸역할별 모양: 탱커는 둥근 사각형, 설계·지원은 육각형, 공격은 삼각형
색캐릭터마다 정한 색. 없으면 팀 색
이름몸 가운데 이름 첫 글자(만, 솜)
바라보는 방향앞쪽에 눈 2개

그림 규격: PNG, 투명 배경, 512×512, 오른쪽을 바라보는 방향, 파일명은 영어 소문자

4. 시연용 단축키

발표 중 흐름이 꼬였을 때 원하는 지점으로 바로 이동하는 키입니다. 어느 장면에서든 똑같이 동작합니다.

키동작이동한 뒤의 상태
R처음부터 다시진행 기록을 모두 지우고 로고부터 시작
18강 경기로 바로파티 2명(만보, 솜)
24강 경기로 바로파티 3명(8강 영입 동료 포함)
3결승 경기로 바로파티 4명(영입 동료 2명 포함)
0엔딩으로 바로파티 4명으로 챔피언 연출 시작
  • 숫자 키는 대진표와 추첨을 건너뛰고 바로 전투로 들어갑니다.
  • 그 앞 경기에서 영입했어야 할 동료는 자동으로 파티에 채워 줍니다.
  • 로고 화면에서 리소스를 불러오는 동안에는 모든 단축키가 동작하지 않습니다.
  • 설정 창이 열려 있어도 동작하며, 이동하면서 창은 닫힙니다.

5. 솜님 확인 필요 사항

아래는 아직 확정되지 않은 내용입니다. 바뀌어도 데이터 수정만으로 반영할 수 있게 만들 예정입니다.

#확인할 내용현재 가정 · 제안구분

7오프닝 상대이름 없는 강한 라이벌 1명제안
8엔딩 마지막 화면자동으로 넘어가지 않고 멈춘 채 유지제안

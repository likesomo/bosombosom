# 라이벌 캐릭터 특징 — 스터디 1기 쇼케이스 작품 기반

> 레퍼런스 이미지: `docs/references/showcase/<팀>_<captain|seed>_<poster|shotN>.jpg`
> 원칙: 작품의 **테마·소품·색감**만 가져온다. 유니티짱 등 작품 속 라이선스 캐릭터의 외형은 쓰지 않는다.

## 1. 대전 순서 (우리 팀 제외 예상 순위 기준)

| 경기 | 상대 | 예상 순위 | 연출 의도 |
|---|---|---|---|
| 8강 | **빌드됐조** | 3위 | 느리게 차오르는 BUILDING 게이지 → 가드 연습, 가볍게 출발 |
| 4강 | **나가자싸우자이기자** | 2위 | 음파 넉백으로 장외 위기감 |
| 결승 | **GenJ** | 1위 | 가장 화려한 네온 연출, 클라이맥스 |

## 2. 대전 상대 3팀

### GenJ (결승) — 네온 견습 셰프
| 항목 | 내용 |
|---|---|
| 멤버 | 캡틴 블늅, 시드 아이고, 얼리버드 미나리 |
| 원작 | 블늅 「점프 업 구르메: 견습셰프의 맛있는 모험」 — 견습 셰프, 큰 식칼, 구리 냄비·프라이팬, 포크 코인, 골렘 보스 / 아이고 「Net Runner」(명예의 전당) — 네온 빗속 사이버펑크 도시, 핑크·시안 네온, 대시 |
| 캐릭터 핵심 | **셰프 모자 + LED 프라이팬 + 사이버펑크 작업복** (요리 × 네온), 머리 장식의 미나리 잎 (얼리버드 미나리) |
| 색 | 검정 바탕, 핫핑크 `#ff3d9a`, 시안 `#33e0ff`, 흰 셰프 모자 |
| 대표 스킬 | 네온 팬케이크 뒤집기 — 근접 띄우기. 프라이팬으로 퍼 올리고 떨어질 때 미나리 고명이 흩날림 |
| 결승 연출 | 경기장 조명이 네온으로 바뀜, 비 내리는 효과(Net Runner) |
| 솜님 시안 | `rival_genj.png` — 셰프 모자, 네온 프라이팬, 핑크·시안 작업복, 미나리 장식. **원작 특징과 거의 그대로 일치** |

### 나가자싸우자이기자 (4강) — 나뭇잎 탐험가 햄스터
| 항목 | 내용 |
|---|---|
| 멤버 | 캡틴 햄쥐터, 시드 듐듐 / 장르 ARPG |
| 원작 | 햄쥐터 「Leaf & Leap」(명예의 전당) — 나뭇잎 탐험가, 황금 나뭇잎, 노란 망토·가죽 가방, **내 목소리 녹음** 기능 / 듐듐 「PROJECT EDEN」 — 가상 배양 공간, 변이체 정화, 시안 와이어프레임 HUD |
| 캐릭터 핵심 | **햄스터(햄쥐터) + 나뭇잎 망토 + 마이크(목소리)** — 함성 스킬의 근거. 단검에 시안 데이터 빛(PROJECT EDEN) |
| 색 | 햄스터 주황·크림, 잎 초록, 시안 포인트 |
| 대표 스킬 | "이기자!!" 함성 — 음파 넉백. 음파 고리 3겹과 나뭇잎이 퍼지며 장외로 밀어냄 |
| 솜님 시안 | `rival_nagaja.png` — 나뭇잎 망토 햄스터, 시안 단검. 원작과 일치. **마이크가 없어** 함성 스킬과의 연결이 약함 |

### 빌드됐조 (8강) — 빌드 로봇
| 항목 | 내용 |
|---|---|
| 멤버 | 캡틴 28병특, 시드 킹너몬 (킹너몬은 1기 작품 없음) |
| 원작 | 28병특 「태풍을 부르는 AI의 신 요스케 구출 대작전」(명예의 전당) — AI 스터디 이야기, 토큰과 **RAM** 수집, 터미널 얼굴(`>_`)의 거대 블록 골렘, 동네 상가 거리 |
| 캐릭터 핵심 | **안전모 + 회로기판 몸 + 터미널 화면 얼굴**, 손에 토큰 코인. "빌드됐다/안 됐다"라는 팀명 개그 |
| 색 | 노란 안전모, 회색 금속, 초록 회로, 초록 체크 화면 |
| 대표 스킬 | 빌드 완료 낙하 — BUILDING… 87%가 다 차면 RAM 블록이 쿵. 가드하면 빨간 BUILD FAILED와 함께 튕겨 나감 |
| 솜님 시안 | `rival_buildedjo.png` — 안전모 로봇, 회로 몸, 체크 화면, 코인. 원작과 일치 |
| 주의 | 원작 포스터의 보라색 젤리 캐릭터는 타사 캐릭터를 닮아 쓰지 않음 |

## 3. 나머지 6팀 (대진표·응원단용)

| 팀 | 멤버 | 원작 핵심 | 캐릭터 키워드 | 솜님 시안 |
|---|---|---|---|---|
| 소서리스 | 포스, 미소 | 포스 「전생했더니 어드벤처 게임」 다크나이트, 보스의 **정수 5개** / 미소 「FiveIsles」 | 보라 마녀 + 다크나이트 그림자, 보석 5개 지팡이 | 일치 |
| 아노게임 | EE, 천원펀치 | 천원펀치 「노리, 화면 밖으로」 삭제를 피해 **화면 밖으로** 도망치는 캐릭터 (EE는 1기 작품 없음) | 토끼 후드, 모니터에서 튀어나오는 주먹 | 일치 |
| 문래빗 | 송지원, 유니 | 송지원 「Sky Jump」 하늘섬 / 유니 「토끼의 정원」 파스텔 잔혹동화, **지워진 문장** | 달 토끼, 동화책 페이지 | 일치 |
| 탄수조아 | 호호, BMO | 호호 「집으로 가는 문」 차원문 / BMO 「은구두」 보스 격파 시 **"컷!" 흑백 촬영장** | 식빵 기사, 몸 절반 흑백 | 일치 |
| 잭팟 | 미요, 케쿠 | 미요 「괴도의 시간」 **카드와 장미**, 재즈 / 케쿠 「Cake Shop」 케이크 배달 | 괴도 실크햇, 777 카드, 케이크 상자 | 일치 |
| 엑스 | 넛츠리, 델타프로그 | 넛츠리 「Curiouser!」 이상한 나라, **티파티**, 흰토끼 / 델타프로그 「유니티쨩 오딧세이」 | 개구리(델타**프로그**), 회중시계, 찻잔 | 일치 |

## 4. 결론
- 솜님 라이벌 시안 11장은 모두 원작 팀장·시드멤버 작품의 핵심 소품을 정확히 담고 있습니다. 시안을 정할 때 이미 이 작품들을 참고한 것으로 보입니다.
- 따라서 GPT 생성은 **솜님 시안을 대체하는 용도가 아니라 비교용**으로, 대전 상대 3팀만 먼저 만듭니다. 비교 결과는 `docs/images/rivals_gpt/compare.md`에 정리합니다.

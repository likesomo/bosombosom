전투를 횡스크롤에서 위에서 본 경기장 방식으로 바꾸기 위해 조사했다. 레조넌스는 비공식 팬게임이므로 **구조와 감각만** 참고하고, 이미지·UI·로고·몬스터볼 무늬 같은 고유 요소는 가져오지 않는다.

## 화면에서 확인한 것
| 요소 | 관찰 |
|---|---|
| 시점 | 위에서 내려다본 한 화면 필드. 카메라 고정. 트레이너전은 바닥 가운데 큰 원형 무늬, 야생전은 풀밭·모래 필드 전체 |
| 캐릭터 | 작은 도트 스프라이트(화면 높이의 1/10 정도), 발밑에 타원 링(내 쪽 파랑, 상대 빨강), 머리 위 이름표 |
| 이동 | 필드 전체를 자유 이동 (분신 여러 마리가 넓게 퍼져 있는 장면 확인) |
| 기술 범위 | 바닥 범위 표시: 상대 바위 낙하 지점에 빨간 테두리 타원 + 어두운 그림자, 수면 기술은 시전자 둘레 큰 원 + 방사선 |
| 바닥 흔적 | 땅 갈라짐, 구덩이 같은 흔적이 전투 후에도 남음 |
| 기술 형태 | 광선(화면을 가로지르는 직선), 투사체, 근접, 바닥 범위 |
| 맞대결 | 광선끼리 부딪치면 가운데 섬광 + 빨간 원 + "맞대결!" "밀어냈다!" 문구 |
| 상태 문구 | "잠듦!", "그림자분신!" 같은 짧은 문구가 캐릭터 위에 뜸 |
| 위쪽 UI | 양쪽 초상화 + 이름·레벨 + HP 바(수치) + 타입 칩 + 능력치 변화(특공▲2), 가운데 타이머 |
| 아래 UI | Q·W·E·R 기술 4칸(타입 칩, PP 수치, 오른쪽 위 쿨타임 숫자), 교체 1~6, 오른쪽에 SPACE 회피 충전 칸 2개 |
| 기술 이름 | 사용 순간 화면 위쪽 모서리에 기술 이름 라벨 (내 쪽 왼쪽, 상대 오른쪽) |

## 나무위키에서 확인한 규칙
- 실시간 전투. 키보드·마우스는 가장 가까운 상대 자동 조준, 게임패드는 오른쪽 스틱 조준.
- 돌진·설치형 기술은 누르고 있는 방향을 쓴다.
- 기술 4칸(Q·W·E·R), 기술별 PP와 재사용 대기시간.
- 회피(Space): 기본 2회 충전, 충전당 3.2초, 무적 시간, 타이밍을 맞추면 완벽 회피.
- 광선 대 광선은 힘겨루기(버튼 연타가 영향), 투사체끼리는 상쇄, 광선 대 투사체는 감속.

## 우리 게임에 적용
| 레조넌스 | 보솜보솜 |
|---|---|
| 한 화면 필드 | 1280×720 한 화면, 타원형 링 경기장 (스매시식 장외를 위해 경계가 보이는 링) |
| 자동 조준 | 같음. 돌진(가시 구르기)은 이동 입력 방향 우선 |
| Q·W·E·R + 회피 | `J` 찌르기, `K` 구르기, `L` 흉내, `Space` 가시 가드 (가드가 우리 핵심) |
| 바닥 범위 표시 | 상대 기술: 준비 동안 빨간 범위가 차오름, 시작 순간 위치·방향 고정 → 걸어서 피할 수 있음. 내 기술: 쓰는 순간 파란 범위 |
| 발밑 링·이름표 | 같음 (보솜이 파랑, 라이벌 팀색 테두리 빨강) |
| 기술 이름 라벨 | 상대 기술 이름을 머리 위에 띄움 (기존 방식 유지) |
| 맞대결 | 시간이 남으면 결승에서만 (선택 작업) |

1. 한눈에 보기

한 줄 요약 — 트로피의 색을 빼앗아 간 "가려진 적"을 쫓아, 보송한 보솜이가 가시로 변신해 라이벌 3경기를 이기고 트로피를 되찾는 2D 실시간 배틀 게임
바뀐 점v1 태그매치v2 보솜이 1인
조작 캐릭터만보 ↔ 솜 교체보솜이 1인
목표우승 + 동료 영입빼앗긴 트로피 탈환
핵심 조작태그 + 합동기가드(가시 반격) + 흉내
대전 상대대진 추첨빌드됐조 → 나가자싸우자이기자 → GenJ
결승 연출일반 경기GenJ가 노이즈에 씌는 2페이즈
승리 후 장면영입 (파티 추가)응원단 합류

2. 장면별 상세

① 로고LogoScene

1.5초
화면 구성검은 배경 가운데 "보솜보솜" 로고가 나타났다 사라짐
입력클릭하거나 아무 키 → 바로 넘어감. 이 첫 클릭부터 소리가 나옴
다음 장면연출 종료 또는 클릭, 리소스 준비 완료 → ② 오프닝 배틀

② 오프닝 배틀OpeningBattleScene

25초 (최대 30초)
진행
  1. 0~3초: 시상대의 챔피언 트로피를 가려진 적이 할퀴자 회색 노이즈로 물듦
  2. 3~6초: 보송한 보솜이 착지. 할퀸 자리부터 털이 회색으로 번짐
  3. 6~8초: 눈이 마주침 → "!" → 털이 터지며 가시로 변신, 색이 돌아옴
  4. 8~16초: 적의 공격 예고 → 가드 키 그림만 크게 깜빡임 → 가드하면 "따끔!" 하고 적이 튕김
  5. 16~22초: 공격 키 그림 깜빡임 → 몇 대 때림
  6. 22~25초: 적이 노이즈로 흩어져 사라지고 트로피는 회색으로 남음. 노이즈 조각이 대진표 쪽으로 날아감 → 암전
다음 장면암전이 끝나면 → ③ 타이틀
안전 장치보솜이는 쓰러지지 않음. 3초 동안 가드를 안 누르면 자동 가드 → 실패가 없는 장면
사용 그림가려진 적 1페이즈, 보솜이 transform·guard·attack 프레임, 표정 surprised

③ 타이틀TitleScene

5초
화면 구성게임 제목, "시작하기"·"설정", 배경에 가시 보솜이와 회색 트로피 실루엣. 게임 종료 메뉴 없음
다음 장면"시작하기" → ④ 대진표

④ 대진표BracketScene

첫 방문 8초 · 이후 4~5초
화면 구성보솜보솜 + 라이벌 9팀, 총 10팀 대진표. 상대는 빌드됐조(8강) → 나가자싸우자이기자(4강) → GenJ(결승)
첫 방문상대 추첨 룰렛(약 3초). 결과는 미리 정한 순서로 고정
다시 방문승리선이 다음 칸으로 이어짐. 관중석에 응원단 라이벌이 보임
결승 직전GenJ 칸이 네온으로 번쩍이다가 한 번 회색 노이즈로 지직거림(복선)
다음 장면다음 경기 칸 클릭 또는 Enter → ⑤ 배틀

⑤ 배틀BattleScene

8강·4강 25초 · 결승 30초
화면 구성
  • 위: 보솜이 체력바(표정 아이콘) / 라이벌 체력바(팀명, 얼굴)
  • 아래: 기술 3칸 — 공격, 가시 구르기, 흉내(흉내 낼 스킬이 없으면 회색)
  • 가운데: 양 끝이 열린 무대, 뒤 관중석에 응원단
핵심 루프
  1. 라이벌이 대표 스킬을 예고하고 사용
  2. 보솜이가 가드 → 가시 상태. 닿은 상대는 "따끔!" 튕김 + 라이벌별 가드 반응 연출
  3. 맞거나 막은 스킬이 흉내 칸에 솜 버전으로 저장 → 쓰면 상대 머리 위에 "?"
승리체력 0 → 잠깐 멈춤 → 장외로 날아가 별이 됨
8강·4강 → ⑥ 응원단 합류, 결승 → ⑦ 엔딩
결승 GenJ네온·비 내리는 경기장. 체력 50%에서 화면 글리치 → GenJ가 회색 노이즈에 씌어 2페이즈(빨라지고 앞 상대 스킬을 섞어 씀). 장외로 날리면 노이즈가 벗겨지고 트로피 색 복구
패배"다시 한 번!" 1초 후 같은 경기를 바로 다시 시작

⑥ 응원단 합류CheerScene

4초
화면 구성장외로 날아갔던 라이벌이 다시 들어옴 → "응원할게!" → 관중석 응원단 칸으로 점프
입력클릭 또는 Enter로 건너뛰기. 누르지 않아도 자동 진행
다음 장면→ ④ 대진표(다음 경기). 결승 후에는 이 장면 없이 엔딩

⑦ 엔딩EndingScene

18초
화면 구성
  1. 트로피 탈환(5초): 회색 트로피에 색이 번지며 반짝임, 보솜이 victory 모션, 응원단 등장, 꽃가루
  2. 개발 로그 크레딧(9초): "기획부터 구현까지 4일" → Day 1~4
  3. 마지막 화면(4초~): "챔피언 보솜보솜의 다음 동료는?" + 빛나는 빈 슬롯 1칸
다음 장면없음. 마지막 화면에 멈춰 발표 멘트로 이어감(R 키로 처음으로)

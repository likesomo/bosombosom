솜 · 버그 플랫포머는 쫓아오는 보스를 함정으로 쓰러뜨리는 3D 횡스크롤 플랫포머예요. 5개 지역에 스테이지 25개가 있고, 지역 끝에서 쫓아오는 보스는 스위치를 밟아 함정을 발동시켜 맞히면 그로기가 돼요. 그때 밟아서 처치해요. 추격 보스 5종, 함정 10종이고, AI 봇 자동 플레이로 125개 경로를 검증했어요. Unity 6.3 URP에 Blender MCP, Claude Code, Codex로 만들었어요.
